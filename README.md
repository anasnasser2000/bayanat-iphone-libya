# مسابقات ايفونات-ليبيا 🇱🇾

موقع مسابقات عربي (RTL) بتصميم أسود/ذهبي/أبيض. الخادم: Node.js + Express. قاعدة البيانات: PostgreSQL. الواجهة: HTML/CSS/JS عادي (بدون خطوة بناء).

## المتطلبات
- Node.js 20 أو أحدث
- قاعدة PostgreSQL (محلية أو من أي مزوّد يعطيك رابط اتصال). **المشروع لا يتضمن قاعدة مستضافة؛ عليك توفيرها.**

## التشغيل المحلي
```bash
npm install
cp .env.example .env        # ثم عدّل DATABASE_URL و PUBLIC_URL
npm run migrate             # ينشئ الجداول
ADMIN_USERNAME=admin ADMIN_PASSWORD='كلمة-سر-طويلة-12+' npm run create-admin
npm run import-questions -- db/sample-questions.json   # اختياري: 12 سؤالًا نموذجيًا
npm start                   # http://localhost:3000   والإدارة: /admin
npm test                    # اختبارات المنطق الأساسي
```

## النشر (بدون Replit)
أي استضافة تدعم Node.js وPostgreSQL (VPS، أو منصات PaaS). الخطوات العامة:
1. ارفع المشروع (مثلًا إلى GitHub) واربطه بالاستضافة.
2. أنشئ قاعدة PostgreSQL وانسخ رابط الاتصال إلى متغير `DATABASE_URL` في إعدادات الاستضافة (وليس داخل الكود).
3. اضبط المتغيرات: `NODE_ENV=production`, `PUBLIC_URL=https://موقعك`, و`PGSSL=true` إن طلبه المزوّد.
4. أمر البناء: `npm install` — أمر التشغيل: `npm start`.
5. نفّذ مرة واحدة: `npm run migrate` ثم `npm run create-admin` (انظر ADMIN_SETUP.md).
6. استخدم HTTPS دائمًا (ملفات تعريف الارتباط تُرسل بخاصية Secure في الإنتاج).

## الأسئلة (1000+)
- من لوحة الإدارة > الأسئلة: إضافة سؤال، أو استيراد ملف JSON (حتى 2000 سؤال لكل عملية)، أو من الطرفية: `npm run import-questions -- ملف.json`.
- صيغة السؤال: `{"text":"...","options":["أ","ب","ج","د"],"correctIndex":0,"level":"easy|medium|hard|special"}`؛ النقاط تلقائيًا 5/10/20/30 حسب المستوى.
- **المرفق يحوي 12 سؤالًا نموذجيًا فقط**؛ عليك إضافة بقية أسئلتك.

## كيف تعمل القواعد
- **الأسئلة:** التحقق من الإجابة في الخادم، والمفتاح الأساسي (المستخدم، السؤال) يمنع احتساب السؤال مرتين.
- **الإعجابات:** مرة واحدة يوميًا لكل زوج مستخدمين، حد أقصى 20 مستلَمة يوميًا، اليوم بتوقيت ليبيا (UTC+2)، ويُقفل صف المستلم داخل المعاملة لمنع التجاوز بالطلبات المتزامنة. لا إعجاب بالنفس.
- **الإحالات:** رابط `?ref=CODE`؛ تصبح مؤهلة بعد أن يجيب المدعو عن `REFERRAL_MIN_ANSWERS` سؤالًا، ثم يحصل الداعي على `REFERRAL_BONUS` نقطة مرة واحدة. المدعو لا يُحتسب إلا مرة واحدة، ولا إحالة ذاتية. التسجيل محدود بـ5 حسابات/ساعة لكل IP. تستطيع الإدارة رفض أي إحالة.
- **الفائزون:** سحب عشوائي آمن (crypto) لـ3 مختلفين أو اختيار يدوي، مع توثيق في سجل التدقيق.
- **الأمان:** كلمات المرور بـ scrypt، جلسات عشوائية مخزّنة كـ hash في القاعدة، كوكي HttpOnly + SameSite، حماية CSRF بترويسة مخصصة، Helmet/CSP، تحديد معدل الدخول، استعلامات مُعلَّمة (لا حقن SQL)، وتهريب HTML في الواجهة.

## ملاحظات صريحة
- صور أجهزة iPhone 18 في الواجهة **رسومات SVG توضيحية**، وليست صور منتج رسمية. `public/og-image.png` صورة بديلة بسيطة: استبدلها بصورة 1200×630 تناسبك قبل مشاركة الرابط على فيسبوك.
- فيسبوك يخزّن المعاينة مؤقتًا: بعد تغيير الصورة أو العنوان استخدم Sharing Debugger لتحديثها.
- لا يوجد إرسال بريد أو استعادة كلمة مرور ذاتية (لا يوجد بريد في التسجيل)؛ تُعاد تهيئة كلمات مرور المستخدمين يدويًا من قاعدة البيانات عند الحاجة.
- راجع الشروط القانونية للمسابقات وإعلانات الجوائز في بلدك قبل الإطلاق.
